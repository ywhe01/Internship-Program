# Demo 演示指南

## 启动

```bash
pip install -r requirements.txt
streamlit run demo/app.py
```

打开终端显示的本地地址，通常为 `http://localhost:8501`。

## 建议演示路径

整段控制在 4–5 分钟。

### 1. 先说明边界

用一句话介绍：

> 邻校掌柜不让模型拍脑袋定价，而是先用门店成本算清楚，再让模型生成可执行内容。

### 2. 展示门店输入

保留默认场景：

- 北门饭堂。
- 照烧鸡腿饭原价 18 元。
- 食材与包装成本 8.2 元。
- 库存 20 份。
- 小雨、晚课日、目标为清库存。

点击“生成今日行动”。

### 3. 解释经营动作

重点指出：

- 建议价 12.9 元。
- 安全底价 10.9 元。
- 单份贡献毛利约 4.1 元。
- 限量 20 份，目标核销 14 份。

强调价格来自确定性计算，不来自大模型。

### 4. 展示素材

切换“素材工坊”：

- 展示群文案、小红书文案和视频分镜。
- 下载活动海报。
- 说明真实模型只是可选润色层，没有密钥也能运行。

### 5. 展示核销复盘

使用默认核销 16 份、自然销量基线 5 份：

- 展示活动流水、贡献毛利和增量贡献毛利。
- 解释为什么要扣除自然销量基线。

### 6. 展示验证看板

说明看板为模拟数据，只用于展示如何做 Go/No-Go：

- 3/5 家付费。
- 采用率超过 60%。
- 平均操作不超过 5 分钟。
- 新增贡献毛利超过两倍月费。

最后落到一句话：

> 真正要验证的不是 AI 能否写文案，而是老板是否愿为可归因的增量毛利付费。

## 模型模式

真实模型模式是可选项：

```bash
set OPENAI_API_KEY=your_key
set OPENAI_MODEL=gpt-4.1-mini
streamlit run demo/app.py
```

macOS/Linux 使用 `export`。

若密钥缺失、网络中断或返回格式异常，系统会自动使用离线策略结果，并在页面提示回退原因。

## 常见问题

### 为什么没有自动发布？

自动发布会增加平台权限、内容合规和错误触达风险。MVP 只验证经营建议是否被采用和是否产生增量毛利。

### 为什么不用模型直接算价格？

价格与毛利属于高风险经营决策，需要可测试、可解释的确定性规则。模型只能改善表达。

### 看板数据是真的吗？

不是。看板明确标注为模拟数据。真实验证必须替换为核销记录和付款凭证。
